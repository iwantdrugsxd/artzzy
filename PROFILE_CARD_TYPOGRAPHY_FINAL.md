### Prompt Questions (Premium Typography)

**Questions** - Elegant, Professional, Serif/Display Style
- Font Family: System Semibold (Ideally: Serif font like Georgia, Times New Roman, or Playfair Display)
- Size: **13px** (increased from 11px)
- Line Height: **20px** (increased from 16px)
- Weight: 600 (Semibold)
- Letter Spacing: **1.8px** (increased for elegance)
- Text Transform: Uppercase
- Color: `rgba(245,245,245,0.52)` (text.muted)

- Margin Bottom: 12px (increased spacing)

### Prompt Answers (Clean, Readable)

**Answers** - Clean Sans-Serif, Larger
- Font Family: System Regular (Humanist sans-serif)
- Size: **16px** (increased from 14px)
- Line Height: **24px** (increased from 22px)
- Weight: 400 (Regular)
- Letter Spacing: 0.2px (subtle for readability)
- Color: `#F5F5F5` (text.primary) - brighter than questions
- Style: Clean, readable, conversational

### Section Labels

**Section Labels** (INTERESTS, etc.)
- Font Family: System Semibold
- Size: 10px
- Line Height: 14px
- Weight: 600 (Semibold)
- Letter Spacing: 1.2px

- Color: `rgba(245,245,245,0.38)` (text.subtle)

## Typography Hierarchy

1. **Primary** (Name): 28px, Bold, -0.5px letter spacing
2. **Secondary** (Answers): 16px, Regular, 24px line height
3. **Tertiary** (Questions): 13px, Semibold, Uppercase, 1.8px letter spacing
4. **Supporting** (Height, Tags): 11-14px
5. **Labels** (Section headers): 10px, Uppercase, Letter-spaced

## Font Recommendations (Future Enhancement)

For a truly premium editorial feel, consider custom fonts:

### Questions (Serif/Display)
- **iOS**: Georgia, Times New Roman, or custom serif
- **Android**: Georgia, serif, or custom serif
- **Custom**: Playfair Display, Merriweather, or similar elegant serif

### Answers (Sans-Serif)
- **iOS**: SF Pro (System), Inter, or custom sans
- **Android**: Roboto (System), Inter, or custom sans
- **Custom**: Inter, SF Pro, or similar clean sans-serif
