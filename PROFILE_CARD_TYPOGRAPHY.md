- Size: 28px
- Line Height: 34px
- Weight: 700 (Bold)
- Letter Spacing: -0.5px

### Q/A Typography (Editorial Style)

**Questions** (Elegant, Professional)
- Font Family: System Semibold (Ideally: Serif/Display font like Playfair Display, Georgia, or similar)
- Size: 11px
- Line Height: 16px
- Weight: 600 (Semibold)
- Letter Spacing: 1.5px
- Text Transform: Uppercase
- Color: `rgba(245,245,245,0.52)` (text.muted)
- Style: Editorial, elegant, slightly letter-spaced, muted

**Answers** (Clean, Readable)
- Font Family: System Regular (Humanist sans-serif)
- Size: 14px
- Line Height: 22px
- Weight: 400 (Regular)
- Color: `#F5F5F5` (text.primary)
- Style: Clean, readable, conversational, brighter than questions

## Typography Hierarchy

1. **Primary** (Name): 28px, Bold, -0.5px letter spacing
2. **Secondary** (Headline): 16px, Semibold
3. **Body** (Paragraph, Answers): 14px, Regular
4. **Tertiary** (Location, Questions): 11-13px, Muted
5. **Labels** (Section headers): 10px, Uppercase, Letter-spaced

## Font Recommendations (Future Enhancement)

For a truly premium editorial feel, consider:
- **Questions**: Playfair Display, Georgia, or Merriweather (serif)
- **Answers**: Inter, SF Pro, or Roboto (clean sans-serif)
- **Headlines**: System Bold or custom display font
